# Forwarder Factory

We preserve Nintendo content for all to download, and maintain several projects such as:

- [Wii Banner Renderer & libwb](https://github.com/ForwarderFactory/wii-banner-renderer) - Utility that renders your Wii channels into a playable video file with OpenGL.
- [netkit](https://github.com/jacnils/netkit) - C/C++23 networking library providing modern, safe sockets and protocol abstractions for Windows, macOS, Linux and DevkitPPC.
- [smbii](https://github.com/jacnils/smbii) - SMB2 server for the Nintendo Wii, allowing you to share your Wii's SD card, NAND or USB storage over the network.
- [hbc-archive](https://github.com/ForwarderFactory/hbc-archive) - Archive of Homebrew Channel versions, installers, exploits and channels.
- [wii](https://github.com/ForwarderFactory/wii) - Now dead archive of Wii homebrew, channels and miscellaneous things.
